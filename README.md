### ポータルのエフェクト
>研究・実装を含めて約20時間

「RINGER」の制作で最初に作成したのは、ポータルのロジックとエフェクトです。\
ポータルのエフェクトは、主に極座標でサンプリングした3Dパーリンノイズと、中心のマスクで構成されています。\
アニメーションは、サンプリング位置を極座標で回転させ、Z座標を縦にずらすことで実装しました。\
また、学習を兼ねて、独自のパーリンノイズ生成関数も実装しています。

### ポータルのロジック
>約10時間

ポータルのロジックは、以下の要素で構成されています。

- 入ったポータルと出るポータルの方向関係に基づく、転移対象物の速度と位置の計算

- ポータル生成時・削除時にリンクを結ぶ・切る処理

- ポータル設置時に、設置場所が適切かどうかの判定

設置場所の判定には Raycast と Layer を使用し、置ける位置かどうかを判断しています。

### ブラックホールのロジック
>約2時間

ブラックホールのロジックは、以下の内容で実装しました。

- 出現・消滅時のアニメーション

- 中心からの距離の2乗に反比例する引力

アニメーションは、シェーダーのスケールパラメーターを LitMotion で滑らかに変化させることで実現しています。

### ブラックホールのエフェクト
>研究・実装を含めて約50時間

「RINGER」の制作において、最も学びが大きかったエフェクト はブラックホールです。

開発初期段階では、RK4（ルンゲ＝クッタ4次） による積分を用いたレイマーチングで重力による空間の歪みを再現しようと試みました。
しかし、2Dゲームではカメラの角度が変わらないため、毎フレームレイマーチングを行うと非効率でした。

そこで、ピクセルごとの歪み情報をテクスチャに保存し、LUT（ルックアップテーブル）として利用すれば、毎フレーム計算せずに空間の歪みを再現できる と考えました。
実際に、ブラックホールの重力によるUV座標の歪みを計算し、テクスチャとして保存するC#スクリプトを作成しました。

ただし、その結果はリアルすぎるブラックホールとなり、ゲームの方向性には合わなかったため没になりました。
現在のブラックホールは、ポータルと似たシェーダーでノイズを重ね、アニメーションさせることで、ゲームの雰囲気に合わせた表現にしています。

### スタンビーム
>研究・実装を含めて約5時間

スタンビームは、ビームの白黒テクスチャを作成し、シェーダーのマスクをアニメーションさせることで実装しました。
ビームのテクスチャを時間に応じてサンプリング座標をずらすことで、エネルギーが流れるような表現にしています。
